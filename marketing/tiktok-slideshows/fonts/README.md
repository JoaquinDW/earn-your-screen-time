# TikTok Sans

TikTok Sans v4.000, 36pt Bold, unmodified. SIL Open Font License 1.1;
the license is included beside the font. Source and release:
https://github.com/tiktok/TikTokSans/releases/tag/v4.000

Native text uses the actual open-source TikTok font. Earnit phone screens
reuse Instrument Serif and Figtree from `App/Resources/Fonts/` through the
existing App Store screenshot sources. No fonts are fetched during rendering.
